## Database Scripts

### Important Notice

The following scripts are kept in the repository for historical and traceability purposes:

- `001-obsolete-do-not-run.sql`
- `002-obsolete-do-not-run.sql`

### Do Not Execute

These scripts must **not be executed under any circumstances**.

They have been marked as obsolete because:
- Their functionality has been replaced by newer scripts
- Running them may cause conflicts, data inconsistencies, or errors in the database

### Purpose

These files are retained only to:
- Preserve commit history
- Maintain traceability of previous database changes

### Current Execution Order

Any database setup or migration process must start from the valid scripts: `003` and onwards.
